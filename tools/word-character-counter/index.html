About this tool

A word counter can help with essays, captions, application forms, articles and social posts. Counting rules vary slightly between platforms, especially for hyphenated words, emoji and abbreviations, so compare with the destination platform when a strict limit applies.

How to use the word & character counter

  1. Enter your values in the calculator above.
  2. Choose the relevant calculation or unit options.
  3. Select the calculate or convert button to view the result.
  4. Review the result and keep any relevant context in mind before using it.

Frequently asked questions

Do spaces count as characters?

The tool shows both the total character count and a count excluding whitespace.

Is my text uploaded?

The counter runs in your browser; the text entered into this tool is not sent to a calculation server.
