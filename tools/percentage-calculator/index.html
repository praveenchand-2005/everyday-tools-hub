Percentage Calculator

Use this free percentage calculator for discounts, marks, budgets, price changes and everyday maths.

About this tool

Percentage calculations are useful for comparing prices, measuring changes and understanding proportions. For example, 20% of 150 is 30. When comparing a starting value and a final value, a positive result indicates an increase and a negative result indicates a decrease.

How to use the percentage calculator

  1. Enter your values in the calculator above.
  2. Choose the relevant calculation or unit options.
  3. Select the calculate or convert button to view the result.
  4. Review the result and keep any relevant context in mind before using it.

Frequently asked questions

How do I calculate X percent of Y?

Multiply Y by X and divide by 100.

How do I calculate percentage change?

Subtract the starting value from the final value, divide by the absolute starting value, then multiply by 100. A zero starting value makes percentage change undefined.
